Roles:
- alibaba/qwen3-32b generates one adversarial variation per v2 seed case
  (prompt_injection, distractor, indirect_phrasing). Its labels are ignored.
- openai/gpt-oss-20b answers each accepted variation with the unchanged v2
  reference prompt and response_format.
- The v2 engine validates every answer against the SEED case expectations of
  support-card-classification-v2, not against anything the generator says.

  intent of the seed. The technique label is checked, not whether the
  technique was actually applied.

  model served each role.

Authentic run protocol (each run requires explicit authorization):
- At most 5 requests: optional fetch, 1 Qwen3 32B, 3 GPT OSS 20B.
- Budget preflight: enforced budget, remaining >= run cap, remaining <=
  exposure cap. Stops on budget, auth, rate limit, pricing, timeout or
  provider errors; no retries, no forced fallback.
- Command, with OTARI_API_KEY set:
    $env:OTARI_LIVE_REDTEAM_ENABLED='1'
    $env:OTARI_RUN_MAX_COST_USD='0.01'
    $env:OTARI_MAX_EXPOSURE_USD='<at least the key remaining balance>'
    $env:OTARI_REDTEAM_FETCH='0'
    npm run redteam-run
- Output: evidence/authentic/redteam-<timestamp>.json, written once (wx), kept
  private. Publish only the copy made by npm run redact-redteam-evidence,
  which removes balances, limits and config.maxExposureUsd and records the
  original SHA-256.
